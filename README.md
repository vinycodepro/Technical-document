# Road Construction Documentation

A responsive technical documentation landing page that explains the main stages of road construction from initial surveying and design through maintenance.

## Live Demo

[View the documentation site](https://vinycodepro.github.io/Technical-document/)

## Overview

This project presents a clear, structured guide to road construction for students, aspiring civil engineers, and anyone interested in how roads are designed and built. The fixed navigation menu makes it easy to move between each stage of the process.

## Topics Covered

- Introduction to road construction
- Surveying and design
- Earthwork and site preparation
- Sub-base and base course construction
- Pavement layers
- Road drainage
- Finishing and quality control
- Road maintenance

## Features

- Responsive layout for desktop and mobile screens
- Fixed sidebar navigation with section links
- Clean technical-documentation design
- Semantic HTML structure
- Readable typography and highlighted engineering terms
- No JavaScript or external dependencies required

## Built With

- HTML5
- CSS3

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vinycodepro/Technical-document.git
   ```

2. Open the project directory:

   ```bash
   cd Technical-document
   ```

3. Open `index.html` in a web browser.

Alternatively, serve the project with any local static web server.

## Browser Support

The page uses standard HTML and CSS and works in current versions of modern browsers, including Chrome, Firefox, Safari, and Edge.
